# Security

Please report security vulnerabilities privately, not in a public issue:
[report a vulnerability](https://github.com/meistyr/winnower-adblock/security/advisories/new).

Include what you found, how to reproduce it, and the winnower version (shown at the bottom of
winnower's menu). I'll acknowledge the report, work on a fix privately, and credit you in the
release notes unless you'd rather not be named.

## Supported versions

Security fixes go into the latest release only.
